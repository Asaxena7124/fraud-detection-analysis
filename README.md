# Fraud Detection Analysis Project Structure

```plaintext
fraud-detection-analysis/
├── data/           ← Store the dataset here (only sample data, do not upload the full CSV)
├── notebooks/      ← Store all Jupyter notebooks here
│   ├── phase1_cleaning.ipynb   ← Uday's work
│   ├── phase2_eda.ipynb        ← Your + Mohan's work
│   └── phase3_model.ipynb      ← Mohan's work
├── visuals/        ← Save all charts and graphs here
└── README.md       ← Project description and documentation
```

## Folder Details

* **data/** → Contains sample datasets used for testing and demonstration.
* **notebooks/** → Contains all Jupyter notebooks related to different project phases.
* **visuals/** → Stores generated plots, graphs, and visual analysis outputs.
* **README.md** → Includes project overview, setup instructions, workflow, and team contributions.

## Workflow

1. Complete data cleaning and preprocessing.
2. Perform exploratory data analysis (EDA).
3. Build and evaluate machine learning models.
4. Save visualizations and maintain proper documentation.
